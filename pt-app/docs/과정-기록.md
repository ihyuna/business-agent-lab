## 4. 과정에서 반복된 것 (보고서용 관찰)

1. **기획 ↔ 개발 고리가 여러 번 돎.** 워크플로우 3번, 시제품 5번 + 웹앱, 그래프 하루에 4번(D86~D89). 한 번 크게 계획하고 만드는 대신 만들고 써 보고 다시 그렸다.
2. **앱보다 사람이 먼저.** 시제품 v2 뒤에 '앱 없는 수업'부터 다시 그렸고(D64), 그 불편한 순간 13개가 v3 화면 4개가 됐다.
3. **제안은 AI, 결정은 사람.** AI가 가짜 기록을 넣었을 때 되돌림(11/03), 확인 안 된 참고문헌은 뺌(11/25), 피그마 문구가 아니라 정했던 안내로 되돌림(11/23). 방향과 기준은 이현아가 정했다.
4. **실제 데이터 원칙.** 모든 화면과 예시는 실제 수첩 숫자. 수첩에 없는 값은 '예시'로 표시.
5. **자료 정리 시간이 거의 사라짐.** 분석·문서·코드 초안은 AI가 만들고, 사람은 읽고 고르고 고치는 데 시간을 씀.
