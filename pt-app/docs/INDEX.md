# PT 기록 앱 문서

프로젝트 폴더의 마크다운 문서를 2026-11-05에 그대로 옮긴 것입니다.

- **회원 이름:** 성+00 코드(이00_1, 이00_2, 이00_3, 김00, 정00, 최00)로만 씁니다. 코드와 실명의 대응표는 올리지 않았습니다(D61).
- **기록:** 숫자와 메모는 트레이너 수첩 그대로이고, 회원 동의를 받아 씁니다(D55).
- **먼저 볼 문서:** `consolidated/`의 네 문서(앱-정의, 워크플로우, 시나리오, 데이터-구조)가 지금 기준입니다. 결정과 열린 질문은 `decisions.md`에 있습니다.
- **빠진 것:** 수첩 사진, 업로드 원본 파일, 프로토타입은 올리지 않았습니다. 프로토타입은 `pt-app/`에 있습니다. 그래서 사진이나 Claude 문서로 가는 링크 일부는 열리지 않습니다.
