## 보낼 질문 (이현아님께 전달한 초안 그대로)

지난번에 답해준 덕분에 앱 구조가 거의 잡혔어! 마지막으로 숫자 기준 세 가지만 확인하고 싶어.
내가 예시를 미리 채워놨는데 대충 넣은 거라 틀려도 괜찮아. **맞으면 "맞음", 다르면 그 부분만 고쳐주면 돼!**

**1. 세트 구성은 실제로 어떤 걸 써?**
쓰는 거 다 골라주고, 빠진 게 있으면 추가해줘.
- 스트레이트 세트 (같은 무게·횟수로 반복)
- 탑세트 + 백오프 (무거운 세트 후 무게 낮춰서 여러 세트)
- 피라미드 (세트마다 무게 올림)
- 역피라미드 (무겁게 시작해서 내림)
- 슈퍼세트 (두 종목 번갈아)
- 자이언트세트 / 서킷 (3종목 이상 연속)
- 드롭세트 (한계 근처에서 바로 무게 내려서 이어감)
- 레스트포즈 (짧게 쉬고 같은 무게로 이어감)

그리고 자주 쓰는 것 1~2개만, 숫자가 어떻게 정해지는지 예시 하나씩 알려줘.
예) 탑세트+백오프 → 탑세트 1세트 6회 여유 1~2개, 백오프는 탑세트 무게에서 10% 내려서 3세트 8~10회
→ 지난번에 "종목·순서랑 세트 구성만 정하면 나머지는 정해진다"고 했잖아. 그 정해지는 규칙을 앱이 알아야 세트 수·횟수·무게·휴식을 자동으로 채워줄 수 있어서 물어보는 거야!

**2. 역할별로 평소 쓰는 기준이 이 정도 맞아?**
(횟수 / 여유 횟수(RIR) / 세트 / 휴식)
- 워밍업: 12~15회 / 5개 이상 남김 / 1~2세트 / 30~60초
- 메인: 6~10회 / 1~3개 / 3~5세트 / 2~3분
- 보조: 8~12회 / 1~2개 / 3세트 / 60~90초
- 마무리 털기: 15~20회 / 0~1개 / 2~3세트 / 30~60초
- 혈류 모으기: 15~25회 / 1~2개 / 2~3세트 / 30초
- 유산소성 순환: 횟수 대신 시간·라운드 / 여유 있게 / 3~4라운드 / 거의 안 쉼

추가로 두 가지만!
- 템포(장력의 시간)는 역할마다 따로 정해? 정한다면 보통 어떻게 해?
- 회원 목표(근력 / 근비대 / 다이어트)에 따라 위 기준이 바뀌는 역할이 있어? 예) 메인인데 근력 목표면 3~6회
→ 앱이 처음 추천할 때 논문 숫자를 그대로 쓰는 게 아니라 이 기준을 출발점으로 쓰고, 기록이 쌓이면 회원별로 보정하려고 해!

**3. 수업 중에 RIR이랑 RPE 중 뭘 써?**
- RIR (몇 개 더 할 수 있었는지)
- RPE (1~10 힘든 정도)
- 둘 다
- 숫자 대신 "쉬움 / 적당 / 힘듦" 정도

그리고
- 회원한테 물어봐, 아니면 보고 판단해?
- 기록한다면 매 세트? 종목 마지막 세트만? 메인 종목만?
→ 아이패드에서 세트마다 입력 칸을 몇 개 둘지 정하려고 해. 종이에 쓰는 것보다 느리면 안 되니까!
