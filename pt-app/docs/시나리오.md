# 시나리오

앱이 실제 수업에서 어떻게 쓰이는지를 장면으로 그린 문서다. 다른 세 문서와 함께 읽는다: 앱-정의.md(무엇을 왜 만드는가, 결정 D·열린 질문 O), 워크플로우.md(업무 흐름과 숫자 규칙), 데이터-구조.md(무엇을 어떻게 저장하는가).

회원은 코드로만 적는다: 이00_1, 이00_2, 이00_3, 김00, 정00, 최00, 그리고 '트레이너 본인', '주인 미상'. 윤 트레이너와 김서연은 가상 인물이다.

|---|---|---|

## 1부. 앱 없는 1시간 PT 시나리오

### 이 문서 읽는 법

앱이 트레이너를 따라가려면, 앱이 없을 때 트레이너가 무엇을 보고 무엇을 정하는지부터 알아야 한다. 이 문서는 가상 트레이너 한 명이 2026-10-07(수) 저녁 이00_3 회원의 하체 수업을 준비하고, 1시간 수업하고, 다음 수업을 정하는 과정을 앱 없이 그린다.

숫자와 메모는 실제 수첩 기록 그대로다. 수첩에 없는 시각, 대화, 컨디션 답은 가정이다. 아래 표시로 둘을 가른다.

| 표시 | 뜻 |
| --- | --- |
| 따옴표 안 글 | 수첩에 실제로 적힌 글이나 트레이너가 설문·인터뷰에 실제로 한 답 |
| [문헌 Schoenfeld 2016] | 논문. 목록은 이 부 끝 |
| (해석) | 기록에 이유가 없어 Claude가 추론한 것 |
| (가정) | 이 시나리오를 위해 정한 것. 수첩과 인터뷰에 없다 |

회원은 성+00 코드로만 쓴다. 오늘 수업이 있는 다른 두 회원도 김00, 최00으로 쓴다.

### 페르소나: 윤 트레이너 (가상)

윤 트레이너는 설문과 인터뷰에 답한 협력 트레이너를 본뜬 가상 인물이다. 이름만 지었다. 습관과 판단 기준은 모두 실제 답과 수첩에서 가져왔다.

수첩의 글씨도 윤 트레이너가 쓴 것으로 본다. 그래서 수첩에 남은 고친 자국과 메모가 곧 윤 트레이너의 판단 흔적이다.

| 항목 | 윤 트레이너 |
| --- | --- |
| 경력 | 1년 미만 |
| 회원과 수업 | 회원 9명, 하루 PT 3~5회 |
| 기록 도구 | 종이 수첩만 쓴다. 회원마다 수첩 칸이 따로 있다. |
| 종이를 쓰는 이유 | "적응할 필요도 없고" 수업 때 들고 다니기 좋다. 휴대폰을 들고 있으면 "예의가 아닌 느낌"이다. |
| 종이의 불편 | "찢어짐 꾸겨짐 관리문제" |
| 언제 적나 | 수업 중에 적는다. 한 번에 3~5분 걸린다. |
| 수업 전에 꼭 아는 것 | 지난 동일 운동의 중량·횟수, 최근 통증, 현재 목표, 지난 컨디션, 개인 운동·식단, 다음에 물어보기로 한 것, 지난 수업 특이사항. "이건 다 알아야 됨." 하나만 고르면 "지금의 목표, 과거의 기록" |
| 기억하기 어려운 것 | 운동 기록, 사용 중량, 생활 습관, 회원 성향 |
| 계획을 짜는 때 | 전주나 정해진 날에 틀을 정한다. 당일 컨디션을 보고 조절한다. 수업 전 카톡이나 대화로 조금씩 조율한다. |
| 미리 정하는 것 | 종목·순서와 세트 구성을 정한다. 그러면 세트 수, 횟수, 중량, 휴식은 따라 정해진다. |
| 종목을 보는 순서 | 그 종목의 목적성(메인, 워밍업, 마무리, 혈류, 순환)이 먼저다. 다음이 앞 종목에서 쓴 볼륨, 그다음이 순서다. |
| 목표를 보는 법 | 장기 목표가 큰 틀이다. 오늘 목표는 그 틀 안에서 컨디션을 보고 가장 효율적인 길이다. |
| 유지할지 올릴지 | 회원의 생활을 본다. 업무 일정, 운동·식단·수면에 집중할 수 있는 시간이다. 여성 회원은 호르몬 주기로 큰 틀을 돌린다. |
| 컨디션 확인 | 수면, 피로, 근육통, 통증을 다 묻는다. 운동 중 눈빛, 몰입도, 집중력을 보고 더 묻는다. |
| 주의사항 | "기억관리는 기본이고 매일 확인도 해야됩니다." |
| 관찰 메모 | 특이하게 튀는 날만 적는다. |
| 숫자를 대하는 태도 | 기록은 쌓는 것이고 "사람은 감으로" 한다. 같은 숫자도 RPE에 따라 다르게 본다. |
| 수첩 쓰는 버릇 | 날짜와 그날 이름을 수업 전에 써 둔다. 기구 세팅을 매번 다시 적는다. 뺀 종목은 줄을 긋고, 이유는 거의 안 쓴다. RIR, 컨디션, 수면, 통증, 휴식 시간은 적지 않는다. |
| 시간을 많이 쓰는 일 | 운동 고민 상담, 자세와 기본기 교정 |
| 기준 | "일 2번 하는 느낌"이 드는 도구는 안 쓴다. |

이 표에서 시나리오의 규칙 셋이 나온다. 첫째, 윤 트레이너는 수업 중 휴대폰을 보지 않는다. 둘째, 계획은 머릿속과 수첩 칸에만 있다. 셋째, 수첩에 안 적는 것은 기억에만 남는다.

### 오늘의 회원: 이00_3

이00_3은 6/24부터 수첩 기록이 있는 회원이다. 8/7까지는 밀기·당기기만 했고, 하체는 8/7 "하체(머신으로 루틴부터 쉽게)"로 처음 들어왔다. 8/24부터는 주마다 하체, 밀기, 당기기 순이다.

오늘은 10/7(수) 하체다. 장기 목표는 수첩에 없다. 이 문서는 10/7 시점의 장기 목표를 '하체 근력과 근육 키우기'로 둔다 (가정).

최근 하체 네 칸은 아래와 같다. 모두 실제 기록이다.

| 종목 | 9/8 | 9/15 | 9/22 | 9/30 |

| 이너타이 | 45kg x 25 | 45 x 20-25 x 2 | 45 x 20-25 x 2 | 45 |
| 시티드 레그컬 | 40 x 20 → 50 x 15 x 2 | 50 x 20 x 2 | 50 x 20 x 3 | 50 |

#### 9/30은 열렸는가

마지막으로 숫자가 남은 수업은 9/24 당기기다. 9/30 칸에는 무게만 있고 횟수·세트가 없다. 수첩만으로는 그날 수업을 했는지 알 수 없다.

이 문서는 9/30 수업이 회원 사정으로 열리지 않았다고 둔다 (가정). 그러면 오늘은 하체 15일 만이고 수업 13일 만이다. 10월 하체 칸에 가벼운 앞 세트가 처음 나오는 것과도 맞는다 (해석).

9/30에 수업을 했다면 윤 트레이너는 60kg을 해 본 기억을 갖고 오늘을 짠다. 그때는 아래 계획에서 '오랜만이라 가볍게' 판단이 빠진다. 대신 "9/30에 60kg을 몇 회 했나"를 기억에서 꺼내야 한다.

### 수업 전 2: 회원 기록 보기 (18:30~18:42)

윤 트레이너는 이00_3 수첩을 편다. 오늘 칸에는 날짜 줄 "10월 7일 하체"만 있다. 앞 장을 넘기며 아래 순서로 본다. 순서는 설문에서 먼저 본다고 한 것부터다,.

#### 18:30 마지막 하체 칸 찾기

바로 앞 하체 칸은 9/30이다. 무게만 적힌 계획 칸이고, 그날은 쉬었다 (가정). 그래서 실제로 한 마지막 하체는 9/22다.

트레이너는 "이 전에 진행한 동일한 루틴과 비교가 필요함"이라고 했다. 수첩에서 그 칸을 찾는 방법은 장을 넘기며 '하체' 글자를 눈으로 찾는 것뿐이다.

#### 18:32 핵스쿼트 줄을 거꾸로 따라가기

#### 18:38 지난 수업 특이사항

마지막 수업은 9/24 당기기다. 바벨로우와 슈러그를 지웠고 메모가 하나 있다. "* 종목 무게 줄이고 다시 기본 첵. (호흡, 가동범위, 텐션유지)".

하체 메모는 아니다. 그래도 '호흡'은 오늘 핵스쿼트에서도 쓸 신호로 머리에 담는다 (해석).

#### 18:40 수첩에 없는 것 떠올리기

1. 개인 운동: 8/19 칸에 "* 개인 운동 상체 진행하기."가 있다. 2주 동안 혼자 운동을 했는지 물어보기로 한다 (가정).

#### 1단계: 오늘 목표

#### 2단계: 60kg은 어디서 나왔나

1. 40kg으로 16회를 했다. 범위 끝 12회를 4회 넘었다. 범위 위를 넘기면 무게를 올리는 방식으로 보인다 (해석).
2. 핵스쿼트는 20, 40, 60으로만 올랐다. 50kg을 쓴 칸은 없다. 이 기구에서 올리는 단위가 20kg일 수 있다 (해석).
3. 핵스쿼트 기구는 받침 무게가 따로 있다. 적힌 숫자가 원판 무게만이라면 실제 부담은 50%만큼 늘지 않는다 (해석).

공식으로 돌려 보면 이 판단과 맞지 않는다. 40kg x 16으로 추정 1RM을 내면 61.3kg이고, 60kg은 1회도 못 드는 무게로 나온다 (계산). 실제 10/7에는 60kg으로 12회를 했다.

추정 공식은 10회 이하 세트에만 맞는다 [문헌 Reynolds 2006]. 그래서 윤 트레이너는 공식을 쓰지 않고 감으로 60kg을 고른다. "사람은 감으로 하는 거고요"의 실제 모습이다.

레그 익스텐션은 이 회원의 하체 칸에서 이미 두 번 빠진 종목이다. 오늘도 같은 자리가 줄었다.

### 수업 중 계획 바꾸기

오늘 수업에서 계획이 세 번 바뀌었다. 세 번 모두 실제 수첩에 흔적이 있다. 바꾼 이유는 수첩에 거의 없어서, 아래 이유는 인터뷰 답과 논문으로 채웠다.

#### 판단 A (19:27): 핵스쿼트 2세트를 못 채웠다

| 단계 | 내용 |
| --- | --- |
| 신호 | 60kg 2세트에서 11회 뒤 12번째를 못 했다. 회원이 "숨이 너무 차요"라고 했다 (가정). |
| 먼저 확인 | 통증이 있는가. 없다 (가정). 통증이면 숫자를 고치지 않고 멈춘다 (D59). 자세가 무너졌는가. 안 무너졌다 (가정). |
| 선택지 | ① 50kg으로 내린다. ② 60kg을 두고 쉬는 시간을 늘린다. ③ 3세트를 뺀다. |
| 고른 것 | ② 쉬는 시간을 5분쯤으로 늘리고 60kg을 둔다. |
| 이유 1 | 막힌 것은 다리가 아니라 숨이다 (해석). 11회도 목표 범위 8~12 안이다. |
| 이유 2 | 세트 사이 3분 휴식이 1분보다 근력·근비대가 모두 컸다 [문헌 Schoenfeld 2016]. 더 쉬면 다음 세트를 채울 수 있다고 본다. |
| 이유 3 | 무게를 내리면 오늘 목표인 '60kg 도전'이 다음으로 밀린다. |
| 이유 4 | 트레이너는 기대보다 안 나오면 "호흡을 과하게 하거나" 같은 이유를 찾는다고 했다. 그래서 무게보다 숨과 쉬는 시간을 먼저 본다. |
| 결과 | 3세트 12회 (가정). 수첩 메모 "* 쉬는 시간이 너무 필요하다. ▽2set에서 1개를 실패." |
| 치른 것 | 핵스쿼트가 계획보다 6분 길어졌다. 그래서 B와 C가 이어진다. |

#### 판단 B (19:36): 레그프레스를 원레그 핵프레스로

| 단계 | 내용 |
| --- | --- |
| 신호 | 3세트 뒤에도 회원이 숨을 고른다. 남은 시간을 세 보니 빠듯하다. |
| 먼저 확인 | 메인 볼륨을 채웠는가. 60kg x (12 + 11 + 12) = 2,100kg으로, 범위 끝 12회로 친 2,160kg의 97%다 (계산). |
| 선택지 | ① 레그프레스 40/40kg x 20 x 2 그대로. ② 레그프레스 세트를 줄인다. ③ 다른 종목으로 바꾼다. |
| 고른 것 | ③ 원레그 핵프레스, 가벼운 무게로 한 다리씩 |
| 이유 1 | 메인에서 볼륨을 채웠으니 뒤 종목은 가볍게 가도 된다. 앞 종목 볼륨을 보고 다음 종목을 정한다는 답과 같은 판단이다. |
| 이유 2 | 한 다리씩 하면 한 번에 드는 무게가 가볍다. 지친 다리에 큰 무게를 다시 싣지 않는다 (해석). |
| 이유 3 | 다리를 번갈아 하니 한쪽이 일하는 동안 다른 쪽이 쉰다. 따로 쉬는 시간을 두지 않아 시간을 아낀다 (해석). |
| 결과 | 수첩에 "~~레그프레스~~ 4 핵프레스(원레그)."가 남았다. 무게와 횟수는 안 적었다. |
| 수첩의 다른 흔적 | 10/14에는 같은 종목 옆에 "(심박수)"를 썼다. 윤 트레이너가 이 종목을 심박을 쓰는 종목으로 본다는 뜻일 수 있다 (해석). |

#### 판단 C (19:50): 레그 익스텐션을 뺀다

| 단계 | 내용 |
| --- | --- |
| 신호 | 지금 19:50이다. 익스텐션 6분과 마무리 5분을 더하면 20:01이다. 회원의 다리가 떨린다. |
| 선택지 | ① 익스텐션 1세트만. ② 스트레칭을 줄이고 익스텐션. ③ 뺀다. |
| 고른 것 | ③ 뺀다. |
| 이유 1 | 오늘 역할이 마무리라 오늘 목표에 덜 중요하다. 트레이너는 종목의 목적성이 순서보다 먼저라고 했다. |
| 이유 2 | 메인 목표는 이미 채웠다. 끝 종목을 빼도 오늘 수업의 뜻은 남는다. |
| 이유 3 | 이 회원 하체 칸에서 이미 두 번 뺀 종목이다(8/14, 9/8). |
| 결과 | 수첩에 "5, ~~레그 익스텐션~~."이 남았다. 다음 하체 10/14에는 순서를 바꿔 30x25x2를 했다. |

#### 다른 경우라면 (가정)

오늘 생기지 않았지만 윤 트레이너가 미리 떠올린 경우다. 모두 가정이고, 근거만 실제다.

| 상황 | 확인할 것 | 바꾸는 법 | 근거 |
| --- | --- | --- | --- |
| "어제 3시간 잤어요" | 첫 세트 속도와 표정 | 60kg은 두되 8~10회에서 한두 개 남기고 멈춘다. 첫 세트가 너무 무거우면 50kg. | 수면 부족 때 하체 수행이 평균 약 3% 낮았고, 저녁 수업에서 더 컸다 [문헌 Craven 2022] |
| 핵스쿼트 중 무릎 통증 | 어디가, 내려갈 때인지 올라올 때인지 | 바로 멈춘다. 무게나 횟수를 고쳐서 이어 가지 않는다. 발판 위치나 종목을 바꾼다. 다음 수업 전 확인할 것으로 기억한다. | D59 임시 규칙, "기억관리는 기본" |
| 60kg 첫 세트가 쉽다 | "몇 개 더 할 수 있어요?" | 남은 세트도 60kg으로 하고 12회에서 끊는다. 올리는 단위가 20kg이라 오늘은 올리지 않는다. | 그날 수행으로 남은 세트를 맞춘다 [문헌 Helms 2018], 20kg 단위 (해석) |
| 회원이 15분 늦음 | 남은 45분 | 이너타이는 가벼운 세트만, 레그컬은 1세트로 줄인다. 핵스쿼트는 그대로, 레그프레스와 익스텐션은 뺀다. | 목적성이 순서보다 먼저다 |
| 혼자 한 운동으로 다리 근육통 | 어느 부위인지, 얼마나 아픈지 | 다리 뒤쪽이면 레그컬을 줄인다. 앞쪽이면 핵스쿼트에서 한두 개 남기고 멈춘다. | 컨디션이 나쁘면 여유를 하나 더 남긴다 (D59) |
| 회원이 "살도 빼고 싶어요" | 장기 목표를 다시 듣는다 | 오늘은 계획대로 하고 끝에 심박을 올리는 종목을 더한다. 다음 계획부터 반영한다. | 장기 목표가 큰 틀이다 |

여섯 가지 모두 윤 트레이너는 머릿속에서 판단한다. 무엇을 보고 바꿨는지는 수첩에 남지 않는다.

#### 방향이 바뀌는 조짐

수첩에서 '숨'과 '심박'이 이어진다. 10/7 "쉬는 시간이 너무 필요하다", 10/14 "(심박수)", 10/16 "라잉 레그컬과 워킹 런지를 통한 심박수 + 체중감량 고려."다.

오늘 본 숨 문제가 다음 주 방향으로 이어졌을 수 있다 [해석, 근거 약함]. 트레이너는 유지할지 발전시킬지를 회원을 보고 정한다고 했다. 그 판단의 재료가 메모 한 줄과 기억뿐이다.

## 2부. 앱으로 하는 수업 시나리오 (MVP v2 기준)

> 2026-10-30: 이 2부는 MVP v2(화면 여섯) 기준이다. 지금 MVP v3의 화면 넷 순서로 다시 짠 8장면은 3부 3-1에 표로 있다. 2부 본문은 v3 순서로 다시 쓸 예정이다.

트레이너가 이00_3 회원의 10/7 하체 수업을 준비하고, 수업하고, 끝내는 과정을 화면과 누르는 순서대로 적은 시나리오다. 앱 워크플로우 v2의 12단계(워크플로우.md 2부)를 실제 하루로 풀어 쓴 것이고, MVP v2는 이 순서대로 다시 만들었다. MVP v2 오른쪽 '시나리오 따라 하기'로 장면 1~8을 그대로 따라 할 수 있다(3부).

숫자와 메모는 트레이너 수첩 기록이다. 수첩에 없는 값(수업 시간, 컨디션 답, 다음 목표 글, 역할과 기준 횟수)은 '예시'로 적었다.

### 등장인물과 상황

이 시나리오에서 회원 등록, 루틴 틀, 훈련 방향(워크플로우 1~3단계)은 이미 끝난 상태다. 트레이너는 수업마다 도는 4~9단계만 한다.

- **트레이너**: 경력 1년 미만, 회원 9명, 하루 PT 3~5회. 지금은 종이 수첩에 수업 중에 적는다. 이 시나리오에서는 수첩 대신 아이패드를 들고 수업한다.
- **회원 이00_3**: 분할은 하체, 밀기, 당기기다. 하체 루틴 틀은 1 이너타이, 2 시티드 레그컬, 3 핵스쿼트, 4 레그프레스, 5 레그 익스텐션이다. 역할은 수첩에 없어 핵스쿼트를 메인, 레그 익스텐션을 마무리 털기, 나머지를 보조로 두었다(예시).
- **핵스쿼트 흐름**: 8/24 20kg으로 시작해 9/8부터 40kg을 했고, 9/22에 40kg × 16회, 12회를 한 뒤 "-▷ 60kg 도전 예정."이라고 적었다. 9/30 하체 칸에는 "60 도전"처럼 무게만 있어 그날 했는지 모른다.
- **날짜**: 9/24 당기기 뒤 10/7(수) 하체, 10/8(목) 밀기, 10/9(금) 후면사슬이 이어지고, 10/12 하체는 14일(수)로 옮겨졌다.

#### 장면 1. 출근 직후, 오늘 수업 확인 (10/7 수)

#### 장면 2. 수업 전, 브리핑 읽기

**화면: 수업 전 브리핑** (한 장, 위에서 아래로 읽는다)

보이는 것(워크플로우 v2 5단계의 7항목 순서):

1. 주의사항: 없음.
2. 다음에 확인할 것: 없음.
3. 오늘 분할: 하체. 지난 같은 분할은 9/22(화). 9/30 하체 칸은 무게만 있어 빼고 본다는 한 줄이 붙는다.
4. 종목별 지난 숫자(9/22): 이너타이 45 × 20-25 × 2, 시티드 레그컬 50 × 20 × 3, 핵스쿼트 40kg × 16, 12(세팅 '발판:1, 밴드o', 9/15), 레그프레스 40/40kg × 20 × 2(세팅 '등받이:1'), 레그 익스텐션 30 × 20.

7. 개인 운동·식단: 없음.

누르는 것:

1. 4번 표의 핵스쿼트 줄을 누른다. 지난 기록이 펼쳐진다: 8/24 20kg × 8-15 × 3, 9/8 40kg × 8-12 × 3, 9/15 40kg × 8-12 × 2, 9/22 40kg × 16, 12. 트레이너는 40kg에서 16회까지 했으니 오늘 60kg이 맞다고 본다.
2. 9/24 메모를 보고 오늘도 호흡과 가동범위를 먼저 보기로 한다(머릿속으로만, 앱에 남는 것은 없다).
3. 오른쪽 아래 '예정 루틴 보기'를 누른다. 다음 화면은 예정 루틴이다.

남는 것: 없음(읽기만 한다).

#### 장면 3. 브리핑 바로 뒤, 예정 루틴 확인과 고치기

**화면: 예정 루틴** (종목 줄 다섯, 숫자는 앱이 미리 채워 둠)

보이는 것: 종목마다 역할, 세트별 무게 × 횟수, 숫자 옆의 작은 꼬리표(어디서 가져온 숫자인지). 숫자는 글자로 보이고, 눌렀을 때만 고치는 칸이 열린다.

| 종목 | 역할(예시) | 앱이 채운 숫자 | 꼬리표 |
| --- | --- | --- | --- |
| 이너타이 | 보조 | 45 × 20-25 × 2 | 같은 분할 9/22 |
| 시티드 레그컬 | 보조 | 50 × 20 × 3 | 같은 분할 9/22 |
| 핵스쿼트 | 메인 | 워밍업 30kg × 12, 45kg × 12 · 본세트 60kg × 8 × 3 | 목표 9/22 |
| 레그프레스 | 보조 | 40/40kg × 20 × 2 | 같은 분할 9/22 |
| 레그 익스텐션 | 마무리 털기 | 30 × 20 | 같은 분할 9/22 |

핵스쿼트의 60kg은 9/22에 남긴 다음 목표이고, 8회 × 3세트는 메인 역할 기준(논문 기준 임시값)이다. 워밍업 30kg, 45kg은 첫 본세트의 50%와 75%다(계산).

누르는 것:

1. 핵스쿼트의 '목표 9/22 !' 꼬리표를 누른다. 근거 카드가 열린다: "9/22 수업 끝에 남긴 다음 목표 60kg ('-▷ 60kg 도전 예정.')", "횟수·세트는 메인 기준 8회 × 3세트(논문 기준 임시값)", "워밍업은 60kg의 50%·75%", "9/30 칸은 무게만 있어 건너뜀". 확인하고 닫는다.
2. 40kg에서 16회를 했으니 60kg도 12회를 노리기로 한다. 본세트 첫 칸 '60kg × 8'을 누르면 그 줄 아래에 고치는 칸이 열린다. 횟수를 12로 바꾸고 '아래 세트에도'를 누른다. 세 칸이 모두 60kg × 12가 되고 꼬리표가 '고침'으로 바뀐다.
3. 워밍업은 한 세트면 된다고 보고 '워밍업 45kg × 12' 칸을 눌러 '이 세트 빼기'를 누른다. 남은 '워밍업 30kg × 12' 칸을 눌러 무게 40, 횟수 8로 바꾼다(숫자 칸에 바로 써도 되고 −, +를 눌러도 된다). 이제 핵스쿼트는 워밍업 40kg × 8, 본세트 60kg × 12 × 3이다.
4. 나머지 네 종목은 그대로 둔다. 저장 버튼은 없고 고친 즉시 남는다.
5. 회원이 오면 오른쪽 아래 '수업 시작'을 누른다. 다음 화면은 수업 시작이다.

남는 것: 예정 루틴의 계획 숫자(고친 것도 포함). 시작을 누르기 전까지는 몇 번이든 고칠 수 있다.

**화면: 수업 시작** (한 장)

보이는 것:

- 컨디션 4줄: 수면, 피로, 근육통은 '평소', 통증은 '없음'이 골라져 있다. 줄마다 오른쪽에 지난번 답이 작게 보인다(이 회원은 '지난번 기록 없음').

누르는 것:

2. 오늘 목표는 그대로 둔다.
3. '시작'을 누른다. 계획 숫자가 고정되고 다음 화면은 수업 진행이다.

남는 것: 컨디션 4항목, 오늘 목표, 시작 시각. 컨디션은 다음 브리핑의 '지난 컨디션'으로 나온다.

#### 장면 5. 수업 중, 세트마다 적기

**화면: 수업 진행** (지금 종목 카드 하나가 크게, 그 아래 다음 종목 한 줄)

보이는 것:

- 맨 위: '이00_3 · 하체 · 목표 핵스쿼트 60kg 도전', 진행 '1/5 종목', 오른쪽에 '수업 끝내기'.
- 종목 카드: 종목 이름, 역할, 지난 세팅, 지난 같은 종목 숫자, 세트 줄. 세트 줄마다 번호, 무게, 횟수, '그대로' 버튼이 있다.
- 숫자를 누르면 그 줄 아래에 고치는 칸이 열린다(−·+, '아래 세트에도', '이 세트에서 통증', '이 세트 빼기'). 숫자를 고치면 그 세트는 고친 숫자로 끝난 것이 된다. 계획 횟수가 '20-25'처럼 범위면 '그대로'를 눌러도 고치는 칸이 열리고, 한 횟수를 넣어야 끝난다. 끝난 세트는 초록색이 되고, 카드의 세트가 다 끝나면 카드 아래 '다음' 줄이 '다음 종목: ○○' 버튼으로 커진다. 그 버튼을 눌러야 다음 종목 카드로 넘어간다. 순서와 상관없이 다른 종목으로 가려면 위쪽 '1/5 종목'을 눌러 목록을 연다.
- 카드 오른쪽 위 '…'를 누르면 바꾸기, 빼기, 순서 위로·아래로, 역할 바꾸기, 숫자 근거 보기가 나온다. 카드 아래에는 '+ 세트'(앞 세트 숫자가 들어온다)와 종목 메모 칸이 있다.

누르는 것(종목별, 수첩 10/7 칸 그대로):

**1. 이너타이** (계획 45 × 20-25 × 2, 수첩 "30x20, 45x20x2")

| 세트 | 계획 | 한 것 | 누르는 것 |
| --- | --- | --- | --- |
| 1 | 45 × 20-25 | 30 × 20 | 무게 45를 눌러 30, 횟수를 눌러 20 |
| 2 | 45 × 20-25 | 45 × 20 | 횟수를 눌러 20 |
| 3 (추가) | 없음 | 45 × 20 | '+ 세트'(앞 세트 숫자가 들어옴), '그대로' |

**2. 시티드 레그컬** (계획 50 × 20 × 3, 수첩 "40x20, 50x25x2")

| 세트 | 계획 | 한 것 | 누르는 것 |
| --- | --- | --- | --- |
| 1 | 50 × 20 | 40 × 20 | 무게를 눌러 40 |
| 2 | 50 × 20 | 50 × 25 | 횟수를 눌러 25 |
| 3 | 50 × 20 | 50 × 25 | 횟수를 눌러 25 |

**3. 핵스쿼트** (장면 3에서 고친 계획, 수첩 "40kg x 8, 60kg. x 12 x 3", "2set에서 1개를 실패")

카드 맨 위에 세팅 '발판:1, 밴드o'와 '지난번 9/22 40kg × 16, 12'가 보인다. 트레이너는 기구를 그대로 맞춘다.

| 세트 | 계획 | 한 것 | 누르는 것 |
| --- | --- | --- | --- |
| 워밍업 | 40 × 8 | 40 × 8 | '그대로' |
| 1 | 60 × 12 | 60 × 12 | '그대로' |
| 2 | 60 × 12 | 60 × 11 | 횟수를 눌러 11 (하나 실패) |
| 3 | 60 × 12 | 60 × 12 | '그대로' |

마지막 세트 아래에 '여유 횟수(선택)' 칩 0~5가 나온다. 수첩에는 없어 누르지 않는다. 세트 수는 수첩에서 판독이 불확실하다.

**4. 레그프레스 → 원레그 핵프레스** (수첩 "~~레그프레스~~ 4 핵프레스(원레그).")

1. 레그프레스 카드의 '…'에서 '바꾸기'를 누른다.
2. 같은 부위(하체) 종목이 먼저 보인다. '원레그 핵프레스'를 고른다.
3. '오늘만'과 '루틴 틀에도' 가운데 '오늘만'을 누른다.
4. 새 카드가 뜨고 꼬리표는 '무게 찾기'다. 처음 하는 종목이라 무게는 비어 있고, 횟수는 보조 기준 10회 × 3세트(예시)다.
5. 수첩에는 숫자가 없다. 앱에서는 첫 세트 무게만 넣어도 다음 수업의 출발점이 된다. 이 시나리오에서는 1세트 무게만 눌러 20을 넣고(횟수 10은 계획대로, 예시) 남은 두 세트는 비워 둔다. 비운 세트는 끝낼 때 '기록 안 함'으로 남는다.

**5. 레그 익스텐션** (수첩 "~~레그 익스텐션~~.")

1. 카드의 '…'에서 '빼기'를 누른다.
2. 이유 칩 다섯(시간, 컨디션, 통증, 기구 없음, 기타) 가운데 '시간'을 누른다. 수첩에는 이유가 없고, 쉬는 시간이 길어 시간이 모자랐을 수 있다고 본 것이다 (해석).

**수업 메모**

카드 아래 '수업 메모'에 "쉬는 시간이 너무 필요하다."를 적는다. 이 메모는 이 수업에만 남는다. 다음에도 보여야 할 것은 종목 메모나 주의사항으로 남긴다.

마지막으로 위쪽 '수업 끝내기'를 누른다. 다음 화면은 수업 후 요약이다.

남는 것: 세트마다 계획과 실제(그대로 누른 것과 고친 것을 구분), 바꾼 종목과 범위(오늘만), 뺀 종목과 이유, 수업 메모.

#### 장면 6. 마지막 세트 뒤, 수업 후 요약

**화면: 수업 후 요약** (한 장, 위는 앱이 계산한 것, 아래는 트레이너가 적는 칸)

보이는 것:

1. 오늘 결과와 지난 같은 분할(9/22): 이너타이 30 × 20, 45 × 20 × 2 (9/22 45 × 20-25 × 2) · 시티드 레그컬 40 × 20, 50 × 25 × 2 (9/22 50 × 20 × 3) · 핵스쿼트 워밍업 40kg × 8, 60kg × 12, 11, 12 (9/22 40kg × 16, 12) · 원레그 핵프레스 20 × 10 (처음, 예시).
2. 계획과 달라진 곳(세트 단위로 나온다): 이너타이 세트 1개 추가와 숫자 고친 세트 2개, 시티드 레그컬 숫자 고친 세트 3개, 핵스쿼트 숫자 고친 세트 1개(2세트 11회), 레그프레스 → 원레그 핵프레스(오늘만), 원레그 핵프레스 숫자 고친 세트 1개와 기록 안 한 세트 2개, 레그 익스텐션 뺌(시간).
3. 넘은 개인 기록: '시티드 레그컬 지난 최고 50 × 20 (8/24) → 오늘 50 × 25', '핵스쿼트 지난 최고 40kg × 16 (9/22) → 오늘 60kg × 12', '원레그 핵프레스 처음 기록 20 × 10'. 축하 말 없이 한 줄씩만 보인다(D11).
4. 다음 목표 칸: 오늘 한 종목마다 무게, 횟수, 짧은 글.
5. 다음에 확인할 것 칸.
6. 주의사항으로 올릴 후보: 수업 메모 "쉬는 시간이 너무 필요하다." 옆에 '주의사항으로' 버튼.
7. 다음 PT: 날짜, 시간, 분할. 분할은 순서상 다음인 '밀기'가 골라져 있다.

'루틴 틀도 고칠까요?'는 이번에는 나오지 않는다. 레그프레스는 '오늘만' 바꿨고 레그 익스텐션은 '시간' 때문에 빼서, 틀을 바꾸려는 변화가 아니기 때문이다 [해석, 워크플로우 v2 9단계].

누르는 것:

1. 결과와 달라진 곳을 훑어보고 틀린 숫자가 있으면 줄을 눌러 고친다(이번에는 없음).
2. 핵스쿼트 다음 목표에 무게 60, 횟수 12, 짧은 글 "3세트 모두 12회"를 적는다(예시). 다른 종목은 비워 둔다. 비운 종목은 다음에 오늘 실제값으로 채워진다.
3. 다음에 확인할 것에 "원레그 핵프레스 시작 무게 다시 보기"를 적는다(예시).
4. 쉬는 시간 메모는 주의사항이 아니라고 보고 누르지 않는다.
5. 다음 PT를 10/8(목), 밀기로 둔다(수첩에서도 다음 날 밀기를 했다).
6. '끝내기'를 누른다. 오늘 화면으로 돌아가고, 이 수업 줄에는 '끝남'이 붙는다.

남는 것: 수업 기록(끝남), 핵스쿼트 다음 목표, 다음에 확인할 것 1개, 10/8 밀기 예정 수업. 앱은 끝내는 순간 10/8 밀기의 예정 루틴 숫자를 미리 채워 둔다. 아무것도 안 적고 끝내도 수업 기록은 저장된다.

#### 장면 7. 다음 하체, 옮기기와 이어지는 숫자 (10/11~10/14)

10/8 밀기와 10/9 후면사슬도 장면 1~6을 같은 순서로 지난다. 10/9 후면사슬은 루틴 틀에 없던 분할이라 그때 틀을 하나 더 만든다(수첩에는 종목 이름만 있다). 10/9를 끝낼 때 다음 PT를 10/12(월) 하체로 잡아 뒀다고 본다.

**수업 옮기기** (화면: 오늘 또는 회원 한눈에의 '다음 PT')

1. 회원이 카톡으로 미루자고 한다(예시). 오늘 화면의 '19:00 · 이00_3 · 하체' 줄 오른쪽 '…'을 누르고 '옮기기'를 누른다.
2. 날짜를 10/14(수)로 고르고 '옮기기'를 누른다. 날짜만 바뀌고 예정 루틴은 그대로다. 수첩에서도 하체 칸의 12일을 지우고 14일로 썼다.

**10/14 브리핑과 예정 루틴** (장면 2, 3과 같은 화면)

브리핑의 '지난 같은 분할'은 이제 10/7이다. '다음에 확인할 것'에는 10/7에 적은 "원레그 핵프레스 시작 무게 다시 보기"가 뜨고, 예정 루틴 숫자는 10/7 기록에서 온다.

| 종목 | 앱이 채운 숫자 | 꼬리표 |
| --- | --- | --- |
| 이너타이 | 30 × 20, 45 × 20 × 2 | 같은 분할 10/7 |
| 시티드 레그컬 | 40 × 20, 50 × 25 × 2 | 같은 분할 10/7 |
| 핵스쿼트 | 워밍업 40kg × 8 · 본세트 60kg × 12 × 3 | 목표 10/7 |
| 레그프레스 | 40/40kg × 20 × 2 | 같은 분할 9/22 (10/7에는 바꿔서 기록 없음) |
| 레그 익스텐션 | 30 × 20 | 같은 분할 9/22 (10/7에는 뺌) |

핵스쿼트 워밍업은 지난번에 실제로 한 워밍업(40kg × 8)을 가져온다. 지난 워밍업이 없을 때만 50%·75%로 계산한다. 그래야 장면 3에서 고친 것을 매번 다시 고치지 않는다.

누르는 것(수업 전, 예정 루틴에서):

1. 이너타이 줄의 '…'에서 '빼기', 이유 '기타'. 수첩 10/14 칸에는 이너타이가 없고 이유도 없다.
2. 레그프레스 줄의 '…'에서 '바꾸기', '원레그 핵프레스', 이번에는 '루틴 틀에도'. 숫자는 10/7에 한 20 × 10으로 채워진다.
3. '수업 시작'을 누르고 장면 4처럼 시작한다.

수업 중(장면 5와 같은 화면, 수첩 10/14 칸):

- 시티드 레그컬: 50 × 20, 60 × 25, 60 × 25. 세 세트 모두 무게를 한 칸씩 올린다.
- 핵스쿼트: 워밍업 40kg은 23회로 고친다. 본세트 60kg은 수첩에 횟수가 없어, 여기서는 '그대로' 세 번으로 둔다(예시).
- 원레그 핵프레스: 수첩은 "20 x 4"다. 20회 × 4세트인지 20 × 4회인지 판독이 불확실해, 여기서는 20회 × 4세트로 본다 (해석). 예정 루틴에는 10/7에 한 세트(20 × 10)만 있어서, 1세트 횟수를 20으로 고친 뒤 '+ 세트'와 '그대로'를 세 번 눌러 4세트를 만든다.
- 레그 익스텐션: 30 × 25 × 2. 횟수를 25로 고치고 '+ 세트', '그대로'.

수업 후 요약에서:

1. 넘은 개인 기록에 세 줄이 나온다: '시티드 레그컬 지난 최고 50 × 25 (10/7) → 오늘 60 × 25', '원레그 핵프레스 지난 최고 20 × 10 (10/7) → 오늘 20 × 20', '레그 익스텐션 지난 최고 30 × 20 (9/22) → 오늘 30 × 25'. 핵스쿼트는 10/7과 같은 60kg × 12라 나오지 않는다.
2. 이번에는 '루틴 틀도 고칠까요?'가 나온다. 이너타이를 '기타'로 뺐기 때문이다. '예, 오늘 것으로'를 누르면 하체 틀의 새 판(10/14)이 생긴다: 시티드 레그컬, 핵스쿼트, 원레그 핵프레스, 레그 익스텐션. 원레그 핵프레스는 이미 '루틴 틀에도'로 바꿔서 다시 묻지 않는다.
3. 다음 PT를 10/15(목) 밀기로 잡고 끝낸다.

남는 것: 날짜를 옮긴 기록, 10/14 수업 기록, 하체 틀의 새 판과 바뀐 날.

#### 장면 8. 몇 주에 한 번, 추이 보고 훈련 방향 정하기

**화면: 회원 한눈에 → 추이**

1. 아래 '회원' 탭에서 이00_3을 누른다. 회원 한눈에가 열린다: 다음 PT, 주의사항, 다음에 확인할 것, 목표와 훈련 방향, 최근 수업 3회.
2. '추이'를 누르고 핵스쿼트를 고른다. 수업마다 가장 무거운 본세트가 선으로 보인다: 8/24 20kg, 8/31~9/22 40kg, 10/7과 10/14 60kg(8/31은 횟수 짝이 불확실). 점을 누르면 그날 숫자와 수첩 원문이 나온다. 체중은 수첩에 없어 비어 있다.
3. 10/16 메모 "라잉 레그컬과 워킹 런지를 통한 심박수 + 체중감량 고려."를 보고 훈련 방향을 정한다. '훈련 방향 바꾸기'에서 발전, 유지, 조절, 집중 가운데 하나와 시작일을 고른다. 어느 것을 고를지는 수첩에 없어 트레이너가 정한다. 앱은 원인을 판단하지 않고 데이터만 보여 준다(D16).

남는 것: 새 훈련 방향과 시작일(지난 방향은 기간으로 남는다).

| 화면 | 들어오는 곳 | 보이는 것 | 누르는 것 → 다음 화면 |

### MVP v1과 v2의 차이

MVP v1은 기능은 거의 다 있었지만, 첫 화면에 예정 수업 전체와 회원 목록이 함께 있고 화면마다 버튼과 입력 칸이 많아 무엇을 먼저 할지 알기 어려웠다. v2는 위 화면 목록의 순서대로 다시 만들었다.

|  | v1 | v2 (지금) |
| --- | --- | --- |
| 첫 화면 | 날짜가 섞인 예정 수업 전체, 회원 목록, 설명 카드가 한 화면에 있다 | '오늘'. 오늘 수업 줄만 보이고, 회원은 아래 '회원' 탭으로 간다 |
| 화면 이동 | 위쪽에 버튼이 여럿 있다 | 화면마다 오른쪽 아래 큰 버튼 하나 |
| 숫자 고치기 | 처음부터 입력 칸이 펼쳐져 있다 | 글자로 보이고 누를 때만 고치는 칸이 열린다. 횟수를 고치면 '아래 세트에도'가 뜬다 |
| 수업 진행 | 왼쪽 종목 목록, 세트 표, 여유 횟수 칩, 관찰 칩, 타이머가 한 화면에 있다 | 지금 종목 카드 하나와 다음 종목 한 줄. 바꾸기·빼기·순서는 '…' 안, 여유 횟수는 마지막 세트 아래에만 |
| 워밍업 | 다음 목표나 규칙으로 채울 때마다 50%·75%로 다시 계산한다 | 지난번 실제 워밍업을 가져오고, 없을 때만 계산한다 |
| 범위 횟수 | '그대로'를 누르면 20-25 같은 범위가 그대로 실제로 남는다 | 범위로 잡힌 세트는 숫자를 넣어야 끝난다 |
| 시연 | '따라 해 보기'가 10/7 수업 하나를 안내한다 | 오른쪽 '시나리오 따라 하기'가 장면 1~8을 차례로 안내한다. 노란 테두리가 누를 곳이고, '이 단계 대신 하기'로 건너뛸 수 있다 |

### 정할 것 (Claude가 고른 기본값)

아래는 시나리오에 없어 Claude가 기본값으로 정한 것이다. 다르게 하고 싶은 것만 말하면 바꾼다.

1. 시연 날짜: 앱의 '오늘'은 10/7(수)에서 시작한다. 장면 7은 10/12(월)에서 시작해 '›'로 10/14(수)로 넘기고, 장면 8은 10/16(금)이다. 오늘 화면 위 '‹ ›'로 날짜를 옮길 수 있다(시연용, 실제 앱에는 없다).
2. 수업 진행 화면에는 왼쪽 종목 목록을 두지 않는다. 다른 종목으로 건너뛰려면 위쪽 '1/5 종목'을 눌러 목록을 연다.
3. 범위로 잡힌 횟수(20-25)에서 '그대로'를 누르면 횟수 칸이 열리고, 숫자를 넣어야 세트가 끝난다.
4. 검색과 설정은 '회원' 탭 위쪽 버튼으로 옮긴다. 시나리오에는 나오지 않는다.
5. 쉬는 시간 타이머는 지금처럼 꺼 둔다.
6. 시나리오 패널에서 앞 장면 번호를 누르면 처음 상태로 되돌린 뒤 그 장면 앞까지 자동으로 채우고, 뒤 장면 번호를 누르면 남은 단계를 대신 채운다. 입력한 것은 그 브라우저에만 남는다.

### 3-1. 웹 MVP v3 (2026-10-30, D65·D66·D67)

**만든 까닭:** 2026-10-28 앱 흐름을 트레이너의 하루 순서로 다시 짰다(워크플로우 v3, D65). 2026-10-30 이현아님이 두 가지를 더 요청했다: 예상과 다르게 한 세트를 넣으면 다음 세트가 실시간으로 바뀌는 것(D66), 기본 추천은 컨디션 '보통' 기준으로 두고 컨디션 때문에 바뀐 무게·횟수는 눈에 띄는 색과 근거로 보이는 것(D67). MVP를 이 두 가지와 화면 넷으로 다시 만들었다.

**무엇인가:** 브라우저에서 여는 HTML 한 파일(외부 라이브러리 없이 순수 JavaScript, 약 195KB), iPad 9세대 가로 1080×810. 비공개 페이지 링크는 v2와 같다. 처음 열면 v2에서 입력한 것은 지우고 처음 데이터로 시작한다.

**화면 넷:**

1. **오늘:** 수업 줄마다 시간, 회원, 분할, 오늘 목표, '마지막 수업 n일 전', 오늘 메모. 줄의 '…'에서 오늘 메모를 한 줄 적는다(카톡에서 들은 말 등). 메모는 그 수업의 준비 화면과 시작 한 장에 다시 뜨고, 수업이 끝나면 내려간다.
2. **수업 준비 (브리핑 + 예정 루틴):** 맨 위 띠 셋(통증·주의사항·물어볼 것과 오늘 메모 / 목표·훈련 방향 / 지난 수업 며칠 전, 계획만 있는 칸 건너뜀, 지난 컨디션, 최근 메모와 지난 같은 분할 메모, 개인 운동·식단). 종목 줄마다 이름·역할·세팅, 가운데에 지난 같은 분할 실제값(누르면 최근 4회와 수첩 원문이 펼쳐짐), 꼬리표(목표·같은 분할·최근·규칙·무게 찾기), 오늘 계획 칩. 숫자는 컨디션 '보통' 기준이다. 아래 '계획 약 N분 / 수업 60분'.
3. **수업:** 계획 수업을 열면 맨 위 '시작' 한 장이 먼저 나온다. 컨디션 네 줄이 '평소'로 골라져 있고, 오른쪽 '오늘 숫자' 표에 수업 준비에서 정한 숫자가 그대로 보인다. 수면·피로·근육통에서 '나쁨'을 누르면 메인·보조 숫자가 **주황색**으로 바뀌고, 누르면 근거가 뜬다. '시작'을 누르면 수업 중 화면이 된다.
   - 위 띠: 지금 시각, 끝까지 남은 분, 남은 종목 예상 분 + 마무리 5분. 빠듯하면 띠가 빨개지고 뒤쪽 종목에 '뺄 수 있음'이 붙는다. '시연 시계 +5분'은 시연용이다(실제 앱은 누른 시각을 쓴다).
   - 종목 카드 하나: 세트 줄마다 '그대로' 또는 숫자 고치기. 끝낸 세트에는 쉰 시간(계획의 2배 넘으면 노란색). 앞 세트 결과로 남은 세트가 바뀌면 바뀐 칸이 **보라색**이 되고 옆에 '수업 중 · 원래 … !' 꼬리표가 붙는다.
   - 바꾸기·빼기 바로 뒤 아래쪽에 이유 칩이 5초 뜬다. 빠듯할 때 뺐으면 '시간'이 미리 골라져 있다. '되돌리기'도 있다.
4. **마무리:** 오늘 결과, 계획과 달라진 곳(색 숫자로 한 세트 수, 오래 쉰 세트 포함), 넘은 기록, 루틴 틀 질문(필요할 때만), 다음에 확인할 것, '다음 같은 분할 초안'(종목마다 오늘 최고 세트, '목표 넘음', '올리기 +눈금' → 숫자 고칠 수 있음, 시간·컨디션 등으로 뺀 종목은 다음에 다시 들어간다는 줄), 다음 PT. '끝내기'를 누르면 다음 수업 준비를 미리 채운다.

### 3-1-3. MVP v4 (2026-11-05, D78): 숫자 판단 중심

이현아님이 8장면 시나리오를 해 보고 "너무 어렵고 왜 하는지가 안 들어가 있다"고 했다. 앱이 하려는 일은 근거를 가지고 세트 수·무게·횟수를 정하는 것이니, 화면과 시나리오를 거기에 맞췄다.

**화면.** 수업 준비 화면을 '오늘 숫자 정하기'로 바꿨다. 종목마다 한 줄에 네 칸이 있다.

| 칸 | 보이는 것 | 예 (10/7 핵스쿼트) |
| --- | --- | --- |
| 지난번 (실제) | 지난 같은 분할에서 실제로 한 숫자. 누르면 최근 4회 | 9/22 40kg × 16, 40kg × 12 |
| 판단 | 오늘 계획 최고 세트와 지난번 실제 최고 세트 비교: 무게·횟수·세트 ↑/↓, 유지, 처음, 무게 찾기 | 무게 ↑ |
| 오늘 세트 | 무게 × 횟수 칩. 누르면 고친다 | 워밍업 30 × 12, 45 × 12, 60kg × 8 × 3 |
| 근거 한 줄 | 숫자가 어디서 왔는지. '계산 보기 ›'로 자세히 | 9/22 수업 끝에 정한 다음 목표 |

주의사항·물어볼 것·목표·지난 수업은 맨 위 한 줄로 접어 두고 '브리핑 펼치기'로 연다.

**시나리오 8장면 (v4.1).** 처음에는 5장면으로 줄였는데, 이현아님이 "양이 많아도 돼. 흐름을 전부 익혀야 하니 … 뭘 하려고, 왜 하는지가 없고 앱 사용이 너무 복잡"하다고 해서 수첩 10/7·10/14 흐름 8장면을 모두 되살렸다. 장면마다 맨 위에 세 칸이 있다: '이 장면에서 하는 일', '상황'(언제, 무슨 일), '왜 하나요'. 단계마다 할 일 아래 '왜:' 한 줄이 붙는다(끝난 단계는 할 일만 남는다).

| 장면 | 이 장면에서 하는 일 |
| --- | --- |
| 1. 출근: 오늘 수업 훑기 | 오늘 수업을 보고, 회원이 미리 한 말("2주 만이라 살살", 가정)을 그 수업에 붙여 둔다 |
| 2. 수업 30분 전: 지난 기록 읽기 | 브리핑, 핵스쿼트 최근 4회, 60kg의 근거를 본다 |
| 3. 같은 화면: 숫자 고치기 | 앱 숫자를 트레이너 판단으로 고친다(60kg × 12, 워밍업 40 × 8 한 세트) |
| 4. 회원 도착: 컨디션 확인 | 피로 '나쁨'이면 무엇이 왜 바뀌는지 보고, 수첩대로 '평소'로 되돌린다 |
| 5. 수업 1시간 | 세트마다 실제 숫자를 남기고, 남은 세트 다시 맞추기(보라색), 판단 A 오래 쉬기·B 바꾸기·C 빼기 |
| 6. 수업 직후 1분 | 목표 넘음 → 다음 목표 올리기(수첩대로 60kg), 다음 PT 잡기 |
| 7. 다음 하체 | 날짜 옮기기, 10/7 목표가 근거와 함께 들어왔는지 확인, 수첩 10/14 그대로 수업 |
| 8. 몇 주 흐름 | 회원 한눈에 → 추이, 훈련 방향 정하기 |

**쉬워진 조작.** 시연에만 필요한 조작(시연 시계 +5분, 날짜 넘기기)은 안내 칸의 버튼 하나('5분 지나기', '10/14로 넘어가기')로 바꿨다. 종목 바꾸기는 '오늘만/루틴 틀에도' 고르고 '바꾸기'를 누르던 것을 버튼 둘('오늘만 바꾸기', '루틴 틀에도 바꾸기')로 줄였다.

자동 테스트로 8장면을 끝까지 돌렸고 오류는 없었다. 이00_3 10/7·10/14 숫자는 v3과 같다(수첩 그대로).
