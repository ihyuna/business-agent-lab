# PT 기록 앱 MVP (웹 프로토타입 v3)

PT 트레이너가 회원 수업을 준비하고, 진행하고, 마무리하는 흐름을 눌러 볼 수 있는 웹 프로토타입입니다. 실제 앱은 iPad 앱으로 만들 예정이고, 이 프로토타입은 화면 흐름을 확인하기 위한 것입니다. 화면 크기는 iPad 9세대 가로(1080×810)에 맞췄고, 디자인은 아직 다듬지 않았습니다.

**데이터는 트레이너 수첩의 실제 기록입니다.** 기록 사용은 회원님들께 허락을 받았고, 이름은 성+00 코드(이00_1, 이00_2, 이00_3, 김00, 정00, 최00)로 바꿨습니다. 실명은 넣지 않습니다. 수첩에 없는 값(역할, 여유 횟수, 쉬는 시간, 기구 눈금 등)은 '예시'나 논문 기준 임시값으로 표시했습니다.

## 여는 법

크롬 등 브라우저에서 `app.html`을 열면 됩니다(파일로 열거나 웹 주소로). 서버나 설치가 필요 없습니다. `index.html`은 Claude 아티팩트용 조각입니다. 입력한 내용은 그 브라우저의 localStorage(`pt-mvp-proto-v3.3`)에만 남고, 화면의 '처음 상태로 되돌리기'로 지울 수 있습니다.

오른쪽 '시나리오 따라 하기' 패널이 8개 장면을 안내합니다. 각 단계에서 직접 누르거나 '대신 하기'를 누르면 됩니다.

## 화면

1. **오늘**: 오늘 수업 목록, 오늘 메모
2. **수업 준비**: 지난 기록 요약과 오늘 계획(무게·횟수 자동 채우기)을 한 화면에
3. **수업**: 시작할 때 컨디션 확인, 세트마다 한 번 누르기, 남은 시간 띠
4. **마무리**: 오늘 바뀐 것, 다음 같은 분할 수업의 초안

숫자 색:

- **주황**: 컨디션(수면·피로·근육통이 '나쁨') 때문에 바뀐 숫자입니다. 기본 숫자는 컨디션이 모두 '보통'일 때를 기준으로 합니다.
- **보라**: 수업 중 세트 결과가 계획과 많이 달라서 남은 세트를 다시 맞춘 숫자입니다.
- 색이 칠해진 숫자를 누르면 원래 숫자, 바꾼 근거, '원래 숫자로' 버튼이 나옵니다.

역할별 기준, 여유 횟수(RIR), 쉬는 시간, 기구 눈금 같은 값은 트레이너 답을 받기 전까지 쓰는 논문 기준 임시값이거나 예시입니다.

## 구조

| 파일 | 내용 |
|---|---|
| `src/00-head.html` | 스타일과 페이지 틀 |
| `src/10-data.js` | 상수, 역할별 기준, 종목 사전, 수첩 기록(코드 이름) |
| `src/20-logic.js` | 숫자 채우기, 컨디션 반영, 실시간 다시 맞추기, 시간 계산 |
| `src/30-views.js`, `src/31-views2.js` | 화면 |
| `src/35-guide.js` | '시나리오 따라 하기' 장면 |
| `src/40-actions.js` | 버튼 동작 |
| `build.sh` | `src/`를 합쳐 `index.html`과 독립 페이지 `app.html`을 만듭니다 |

`index.html`은 빌드 결과물입니다. `src/`를 고친 뒤 다시 만들어 주세요.

## 빌드와 테스트

```sh
sh build.sh          # index.html, app.html 다시 만들기
node test/smoke.js   # 8개 장면을 끝까지 자동으로 돌려 보고 결과와 오류를 출력
node test/check.js   # 장면 1~7을 한 단계씩 돌리며 시간 띠·색 표시 상태를 출력
```

테스트는 Playwright와 Chromium이 필요합니다. `check.js`는 `smoke.js`가 만든 `test/page.html`을 쓰므로 `smoke.js`를 먼저 돌립니다.

## 사용한 외부 자료

- 근육 지도의 사람 그림 좌표(`src/15-body.js`)는 [react-body-highlighter](https://github.com/giavinh79/react-body-highlighter) v2.0.5 (MIT License, Copyright (c) 2020 GV79)의 그림 데이터에서 숫자만 옮겼습니다.

# 짐노트 웹앱 (`web/`)

시연판(`app.html`)과 같은 화면·계산을 쓰되, 트레이너가 실제로 쓰도록 바꾼 웹앱입니다. 지도교수님 피드백(11/11)대로 아이패드 앱 대신 웹앱이고, 화면 기준은 그대로 아이패드 9세대(1080×810)입니다.

| | 시연판 `app.html` | 웹앱 `web/index.html` |
|---|---|---|
| 오늘 날짜 | 2026-10-07 고정, ‹ › 로 넘김 | 실제 오늘 (‹ › 로 넘겨 보고 '오늘로') |
| 수업 중 시계 | 세트마다 정해진 분만큼 가는 시연 시계 | 실제 시각. 쉬는 시간 = 앞 세트를 끝낸 뒤 지난 시간 |
| 시작 화면 | 로그인 모양(시연) | 로그인 없음. '수첩 기록으로 시작' / '빈 노트로 시작' / '백업 파일 불러오기' |
| 시나리오 안내, 도구 줄 | 있음 | 없음 |
| 예시 취소·안 옴 | 있음(설정에서 숨김) | 넣지 않음 |
| 저장 | localStorage `pt-mvp-proto-v4` | localStorage `jimnote-v1` (시연판과 섞이지 않음) |
| 백업 | 없음 | 설정 → 백업 파일 내려받기 / 불러오기 / 모두 지우기 |
| 오프라인·홈 화면 | 없음 | 서비스 워커(`sw.js`)와 `manifest.webmanifest`. 한 번 연 뒤에는 인터넷 없이 열리고, 아이패드 사파리에서 '홈 화면에 추가'하면 앱처럼 열림 |

'수첩 기록으로 시작'은 시연판과 같은 수첩 기록(회원 6명, 성+00 코드)을 넣습니다. 수첩에 없는 지난 날짜의 예정 수업(시연용으로 잡아 둔 것)은 넣지 않습니다. 기록 숫자는 바꾸지 않습니다.

기록은 그 기기의 브라우저에만 남고 어디로도 보내지 않습니다. 서버와 로그인이 없어서 기기끼리 맞추려면 백업 파일을 옮겨야 합니다. 브라우저 기록을 지우면 기록도 지워지니 백업 파일을 가끔 받아 두세요.

여는 법: GitHub Pages를 켜면 `https://ihyuna.github.io/business-agent-lab/pt-app/web/` 에서 열립니다(저장소 Settings → Pages → Branch `main`, 폴더 `/ (root)`). 서비스 워커는 http(s)에서만 돌아서, 파일로 열면 오프라인·홈 화면 기능만 빠지고 나머지는 됩니다.

코드: `src/` 를 시연판과 같이 쓰고, 웹앱에만 `src/50-web.js` 가 더 들어갑니다(`35-guide.js` 는 빠짐). 소스 안의 `WEBAPP` 값으로 둘을 가릅니다. `sh build.sh` 가 `web/index.html` 도 같이 만듭니다. `web/sw.js`, `web/manifest.webmanifest`, 아이콘은 직접 고치는 파일입니다.

```sh
sh build.sh          # index.html, app.html, web/index.html
node test/web.js     # 웹앱: 처음 시작 → 다음 PT 잡기 → 수업 → 새로고침 뒤 유지 → 백업·지우기·불러오기 → 빈 노트 → 세로 화면, 오류 출력
```
