# 가명 처리한 실제 데이터 기록

트레이너가 손으로 쓴 PT 수첩 기록입니다. 회원 동의를 받아 쓰고(D55), 이름은 성+00 코드로만 적었습니다(D61). 코드와 실명의 대응표는 올리지 않았습니다.

| 파일 | 내용 |
|---|---|
| `수첩-기록/<코드>/` | 수첩 사진을 글로 옮긴 판독본. 지운 숫자, 화살표, 판독 불확실 표시까지 수첩 그대로 |
| `수첩-기록.json` | 프로토타입이 읽는 형태로 정리한 수업 기록. 회원 6명, 수업 157개 |

- 수첩에 없는 값은 넣지 않았습니다. 숫자가 애매한 줄은 세트를 비우고, 수첩 글은 그대로 남겼습니다.
- 수첩에는 취소·안 옴 기록이 없습니다. 프로토타입 화면의 취소·안 옴은 '예시'로 표시한 예시 데이터이고, 이 폴더에는 없습니다(D75).
- 회원 코드: 이00_1, 이00_2, 이00_3, 김00, 정00, 최00. 이 밖에 트레이너 본인 기록이 있습니다.
